## 📌 Sobre o Projeto

Este projeto é um site institucional desenvolvido para a Dantas Elevadores. O objetivo principal foi criar uma presença digital profissional e moderna, destacando os serviços oferecidos e facilitando o canal de comunicação com os clientes. A interface foi construída para transmitir segurança e credibilidade, alinhando a estrutura web de forma coerente com a identidade visual da marca.

## 🛠 Tecnologias utilizadas:

## 📚 Alguns conceitos aplicados

Neste projeto apliquei os seguintes pontos:

✔️ Semântica HTML para otimização de buscas (SEO);

✔️ Design Corporativo focado na apresentação de serviços;

✔️ Responsividade e adaptação para dispositivos móveis;

✔️ Organização estrutural com CSS Variables e Flexbox/Grid;

✔️ Experiência do Usuário (UX) voltada para captação de contatos.
